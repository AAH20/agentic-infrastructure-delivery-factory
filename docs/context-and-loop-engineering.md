# Context and loop engineering

1. Immutable authority: policy, regions, budgets and prohibited actions.
2. Infrastructure graph: resources, dependencies, owners and business capabilities.
3. Episodic memory: prior changes, incidents, approvals and rollback outcomes.
4. Working context: bounded dependency subgraph plus the active change.

Loop: observe → retrieve → plan → validate → simulate → evaluate → approve → apply → verify → learn. A failed verification produces rollback, not a success receipt. Prediction is a declared reference logistic formula, not a trained production model.
